# Веб-сервис для управления движением денежных средств (ДДС)

Этот проект представляет собой веб-приложение для учета, управления и анализа поступлений и списаний денежных средств компании или частного лица. Пользователи могут создавать, редактировать, удалять и просматривать записи о движении денежных средств.

## Возможности приложения

- Создание записи о движении денежных средств с параметрами:
  - Дата создания записи
  - Статус (Бизнес, Личное, Налог)
  - Тип (Пополнение, Списание)
  - Категория и подкатегория
  - Сумма
  - Комментарий
- Просмотр списка всех записей с фильтрацией по различным параметрам
- Редактирование и удаление записей
- Управление справочниками для статусов, типов, категорий и подкатегорий

## Технологии

- Python
- Django (с использованием Django ORM)
- SQLite (или любая другая реляционная база данных)
- Frontend: HTML, CSS (Bootstrap), JavaScript

## Установка

1. Клонируйте этот репозиторий:

   ```bash
   git clone https://github.com/MaximOdeg/DDS/tree/feature_1
   cd ваш_репозиторий
   
2. Создайте виртуальное окружение:

python -m venv venv

3. Активируйте виртуальное окружение:

Для Windows:

venv\Scripts\activate

Для macOS/Linux:

source venv/bin/activate

4. Установите зависимости с помощью pip:

pip install -r requirements.txt

5. Настройка базы данных
Перейдите в каталог проекта и выполните миграции:

python manage.py migrate

6. Создайте суперпользователя для доступа к административной панели:

python manage.py createsuperuser

7. Запуск проекта
Запустите сервер разработки:

python manage.py runserver

Теперь вы можете открыть приложение в браузере по адресу http://127.0.0.1:8000/.
Вы можете увидеть документацию API, перейдя по URL-адресу http://127.0.0.1:8000/swagger/
